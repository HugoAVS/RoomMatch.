# Rommatch

Rommatch conecta estudiantes y profesionales con compañeros de vivienda
compatibles, y a arrendadores con arrendatarios calificados. Combina una
experiencia de matching estilo tarjetas con una Progressive Web App (PWA)
instalable.

> "Encuentra tu espacio. Encuentra tu match."

## Estructura del monorepo

```
RoomMatch/
├── frontend/   # React + TypeScript + Tailwind CSS (Vite, PWA)
└── backend/    # Node.js + Express + TypeScript + Prisma (PostgreSQL)
```

## Sprint 1 — Cimientos de la PWA

- Setup del repositorio y estructura de carpetas frontend/backend.
- `manifest.json` con iconos, color de tema `#164E63` y modo `standalone`.
- Service Worker básico con precaché del App Shell.
- Pantalla de bienvenida minimalista y verificación del prompt de instalación.
- Esquema inicial de base de datos en PostgreSQL con Prisma ORM.

## Desarrollo local

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
```
